# Witty Add-on 0.6.21

Release: 23.09.2026

- Auf Raspberry Pi 4 wird der Add-on-Webserver auf Port 8081 auch bei
  „Kein Witty“ und einer reinen WURB-/WIRC-Installation zwingend eingerichtet.
- Fehler bei Webserver, HTTP-Prüfung oder Navigations-Patch werden nicht mehr
  still als optionale Warnung übergangen.
- Das optionale Zeitzonenpaket kann die Homepage-Installation auf einem
  langsameren Pi 4 nicht mehr verhindern.
- WURB und WIRC zeigen ohne Platine den Link „Witty Addon“.
- Ein Update repariert eine bisher fehlende Add-on-Homepage und setzt die
  Navigation erneut.

Auf GitHub liegt ausschließlich das verschlüsselte Paket
`witty_addon.zip.enc`; eine unverschlüsselte `witty_addon.zip` wird nicht
veröffentlicht.
