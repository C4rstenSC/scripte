# Witty Add-on 0.9.9

Witty Add-on 0.9.9 – Build 3

- WURB und WIRC können im Windows-Programm auch bei aktueller Version und gestopptem Dienst erneut aktualisiert werden.
- Dienstaktionen warten nicht auf die Witty-Hardware-Sperre und benötigen keine separaten Dienst-Wrapper.
- WURB/WIRC stoppen deaktiviert auch den automatischen Start; Starten aktiviert ihn wieder, für Witty Pi 3, 4 und 5.
