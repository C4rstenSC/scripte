Version 1.0.25 – 25 October 2026

- Release the previous download session after an automatic Allsky reboot even when the final terminal completion marker could not be sent. Subsequent Linux and software updates are no longer blocked by that old session.
- Disconnect clears local download resources and busy state without issuing a reboot or shutdown command. Ignore late output from closed terminal streams.
- When an operation is genuinely running, update buttons show an explanation and expand the SSH terminal.
- Print a visible Linux-update success message. Following confirmed success and a successful status refresh, collapse the terminal and scroll the Raspberry view to the top. Keep errors visible.
- Apply the same completion behaviour to fresh-image Linux updates without an installed Witty add-on.
- Retain the Allsky installation/recovery/date and SD progress fixes from 1.0.24.
