Version 1.0.4 · Build 1
Changes since 1.0.3

Windows device clocks
- Show Raspberry system time and Witty Pi time, including date and seconds, between the current Witty configuration and the restart/shutdown buttons.
- Below the clocks, show homepage GPS latitude/longitude and used/visible satellite counts when available. Missing values are not replaced with zero.
- Show a third row only while valid GPS time is available.
- Read the same homepage API as the device web interface. Preserve the device timezone; never replace readings with Windows time or timezone.
- Advance seconds between polls using monotonic elapsed time and compensate individual measurement ages. Refresh Raspberry/Witty readings periodically and GPS independently.
- Invalidate failed or stale readings. Stop polling on disconnect, host-tab closure and planned reboot; restart with fresh readings after reconnection.
- Each host retains its own readings and polling. Labels follow the selected language.

Retain the 1.0.3 PC clock preflight, original firmware download and explicit date parser.
