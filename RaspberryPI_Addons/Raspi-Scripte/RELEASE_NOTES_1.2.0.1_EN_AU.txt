Version 1.2.0.1 – Homepage, startup status and script activation

1. Automatic power-on and preferred power input lead Additional settings before input voltage. Internal Pi RTC precedes RPI - reboot and RPI - shut down.
2. Date/time inputs align vertically with actions beside them; redundant manual labels removed. GPS buttons are renamed GPS => system time + Witty Pi RTC and GPS => Witty Pi RTC without changing their actions. Mobile rows wrap and GPS buttons stack.
3. Windows homepage buttons align beside the matching software rows.
4. Original WURB Accepted formats guidance sits below Save on desktop/mobile, preserving original text/visibility.
5. GPS time-zone database loads on demand. Quick status waits up to two seconds for the backend lock, retries initial failures, and shows current-data/time labels only after success.
6. Activate is hidden after END using Witty RTC, even while the page stays open. Backend preflight rejects expired known sources. Editing/deleting remain possible; dates are not changed automatically.
7. Activation gives immediate elapsed-time feedback. Terminal firmware errors do not cause minutes of repeated activation/alarm reset. Activation finished, but… is a failure; only a confirming manufacturer reply establishes success.
8. Automatic PC time correction before base installation/Witty update remains limited to differences exceeding 48 hours.
Validation at that release covered Windows cross-build and targeted Python/JavaScript tests. No physical Raspberry/Witty or native WPF test was performed.
