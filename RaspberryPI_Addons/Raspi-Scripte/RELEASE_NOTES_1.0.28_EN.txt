Version 1.0.28 – changes since 1.0.27

Windows Allsky installs/updates temporarily use the PC UTC epoch on Linux only for signed package downloads. The Witty RTC is never overwritten. Existing verified Witty-to-Linux synchronization restores the master clock before Allsky startup/reboot and on normal installer errors. Fixed offsets, timezone and DST mode are retained, including fixed UTC+10 in Sydney. Signed package indexes are checked before moving the existing Allsky project.
Add-on updates now repair the offline GPS timezone database using the same setup as new installations, with Berlin/Sydney coordinate checks. The web service uses its Python environment with unnecessary Numba JIT disabled. GPS suggestions cannot replace an active fixed UTC+10 selection. Missing/broken optional lookup dependencies are reported clearly without taking the whole homepage down.
Install Windows 1.0.28, then Witty Add-on 1.0.28 before updating Allsky. Temporary PC time requires a correctly set PC clock; direct web installs have no PC time source. Boot-file preservation from 1.0.27 remains. Automated tests and real timezone database queries passed; the temporary clock path has not been tested on the physical Pi.
