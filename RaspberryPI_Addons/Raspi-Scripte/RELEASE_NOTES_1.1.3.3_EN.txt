Version 1.1.3.3 – 2026-11-01

The Windows pre-install clock check no longer requires the Add-on backend
on a clean Raspberry. It checks Linux time first; a confirmed PC time sync
sets Linux only at this stage and never fabricates a Witty RTC time.
Existing installation markers with a missing backend still cause an error.
An existing backend retains the requested RTC verification and synchronization.

Windows content update only, without EXE/module changes. Bundled Witty Add-on
remains unchanged at 1.1.3.2. Eight targeted software tests passed. No complete
Windows installation test on physical hardware. The previous card's boot
failure is not established as fixed by this preflight correction.
