Version 0.9.7.1 · Build 5
Changes since 0.9.7.1 Build 4

Windows interface
- Opening and closing application messages releases mouse capture and restores pointer visibility. Returning to the main window or moving the mouse also restores a pointer left hidden by WebView2. Windows mouse preferences are unchanged.
- Confirmation dialogs suspend terminal input and automatic focus reclamation in both the application and terminal page. The embedded terminal control is no longer disabled and re-enabled for this purpose.
- The Witty add-on update button is darkened and disabled when neither a newer version nor a newer build is available. Missing base installation and busy operations still disable it.

Diagnostic status
- The user reported successful startup without Ethernet and a successful restart with Ethernet while the GPS time service was masked. One successful comparison does not prove the cause; the GPS/RTC path remains under investigation.
- Build 5 does not change GPS time synchronization. Build 4's ten-second reconnection pause and targeted update logic remain included.
