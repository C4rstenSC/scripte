Version 0.9.7 · Build 1
Changes since 0.9.5

Multiple Raspberry connections
- Host tabs below the connection panel retain independent SSH clients, terminals, status, configuration, installation files and restart monitoring. Switching tabs does not change the target of a running operation.
- Tabs show hostname, connection indicator and a close button. Closing disconnects only that host; remaining tabs move left. The header lists connections vertically.
- Double-click a discovery row to connect. Single-click still selects. Open hosts are filtered by hostname and IP address.

Base installation and update output
- Micro-SD maintenance remains available without base installation. Individual software installation and release-notes buttons are hidden. The Witty software row omits the not-installed text. Installation actions also enforce the prerequisite.
- Add-on updates report current steps, file transfer and live output from longer commands. Duplicate release headings are removed.
- Windows displays the add-on version and numbered build without a date.

Pi 3 and Witty Pi 3
- Raspberry Pi 3B and 3B+ support WURB/WIRC on 64-bit Bookworm/Trixie Lite. SD model choices are 3B, 3B+, 4/4B and 5.
- Attached Witty Pi 3 hardware is detected independently of installed software at MCU 0x69 and RTC 0x68. Manufacturer installation and homepage script management use classic WPI scripts, without applying Pi-4 register addresses to Pi 3.
- Witty Pi 3 installation adapts GPIO access to pinctrl, checks GPIO-4 conflicts, enables I2C/UART settings and waits for manufacturer service readiness. Base installation defers starting that service until reboot.
- Pi 3 USB GPS uses the Pi-4 data path. Partition maintenance and manufacturer shutdown support model 3 while retaining UUID and filesystem checks.

Allsky
- Allsky is offered only on Raspberry Pi 5, with additional installer and backend checks.
- The older archive installer activates its existing Python environment on Trixie too, addressing the observed NumPy PEP-668 failure without bypassing system Python protection. All three sources are checked for repeatable preparation.

Validation limits
- Software checks cover hardware identity, script management, GPS selection, maintenance flow, Allsky Python paths and independent Windows host tabs. Physical Witty Pi 3 power-off, camera capture and complete installation still need device testing.
