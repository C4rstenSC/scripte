Version 1.1.3.5 – 2026-11-01

Pi-5 backend hardware actions wait for systemd startup completion and initialization messages from the current WP5 MainPID. Pending status returns actual Linux time and no invented Witty time. GPS and shutdown-cache initialization wait independently in the background, without adding a multi-user.target dependency. Explicit Linux-only manual time setting remains available. Original manufacturer daemon and required Allsky boot clock adapter are unchanged.

Pi-5 GPS automation retries read-only fix detection, then attempts clock synchronization at most once. Missing Witty status prevents clock writes and WP5 stops. Failed transactions do not restart a write loop. Legacy Pi-3/4 action paths are preserved.

Terminal reset no longer restores a stale normal-buffer cursor to 0,0. Verified native new-connection banner after reset clears the prior session; collapse preserves the same session. Hidden views do not force a minimum PTY grid.

Diagnosis includes preparation, marked attempt and current recovery by immutable boot IDs, with current-plus-two-predecessors fallback. Old boot trees are excluded, exports are per boot, source evidence is not deleted. Per-phase durations and five-second heartbeat added. Redundant recursive dependency listing reduced; explicit unit names fix an empty runtime-properties report.

Targeted software and real-xterm tests, syntax/regression checks and encryption roundtrip. No physical boot test; early power-off cause remains unresolved. Saved-record cutoff is not physical failure time. Windows content and Add-on 1.1.3.5, no EXE/module or manufacturer firmware replacement.
