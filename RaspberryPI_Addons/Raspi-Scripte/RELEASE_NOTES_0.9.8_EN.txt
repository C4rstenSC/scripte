SSH terminal after Witty update

Validation
- The actual launcher event flow and subsequent shell input/reply were tested across all byte chunk sizes, including reconnect after an incomplete block.
- Native compilation checks the Windows application and updater. Pi hotspot interaction still requires a device test.
