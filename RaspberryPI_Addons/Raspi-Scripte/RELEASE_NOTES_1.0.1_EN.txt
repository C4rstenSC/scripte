Version 1.0.1 · Build 5

- Shared USB mounting for WURB and all offered Allsky versions. Base + Allsky without WURB also installs pmount and mount rules, without downloading a WURB repository just for those files.
- USB data filesystems use the existing WURB /media/USB-<device> convention, including hotplug, reboot and already connected sticks.
- Witty Add-on updates retrofit the mount integration even for unchanged existing Allsky/WURB installations. Already mounted storage remains untouched; internal disks and unsupported filesystems are skipped.
- Allsky add-on installation, version changes, reinstallation and first boot after an immediate installer reboot use the same mount integration.
- Witty Pi 5 manufacturer installation/update preserves the pre-install Linux epoch and timezone, restores installation-induced clock jumps using monotonic elapsed time, then synchronises and verifies the Witty RTC.
- No fixed hour correction or new periodic clock service; the source is the Linux time present before manufacturer installation.
