Version 1.0.1 · Build 2
Changes since Build 1

- Release Ethernet 30 seconds after boot instead of 15 seconds.
- Wait only for NetworkManager, no longer for completion of Allsky, WURB, WIRC, GPS or Witty service startup. Long-running application starts can no longer hold Ethernet back.
- Applies to new installations and Witty updates; the Windows package bundles the same updated installer.
- Updating preserves the current network connection. The delay applies after the next normal reboot.
